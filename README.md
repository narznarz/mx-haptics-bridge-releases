## Install / 설치

1. Download the zip (do not unzip).
2. Blender: `Edit > Preferences > Add-ons > Install from Disk`.
3. Select the zip, then enable **MX Haptics Bridge (HANGULO Pipe)**.

1. zip을 내려받는다 (압축 해제하지 않는다).
2. Blender: `Edit > Preferences > Add-ons > Install from Disk`.
3. zip을 선택하고 **MX Haptics Bridge (HANGULO Pipe)** 를 켠다.

## Requirements / 필요 환경

- Windows 10/11
- Blender 3.6 or newer
- HanguloHapticsPlugin (provides the `hangulo-haptics-addon` named pipe)
- Logitech MX Master mouse (haptics)

## Features / 기능

- Click, hover, drag, UI slider drag haptics
- Snap haptics for object, pose and edit-mode transforms
- Ctrl temporary snapping supported
- Localized UI: English, 한국어, 简体中文, 日本語

Install instructions and change notes are included in each release.
